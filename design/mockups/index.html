rustyWings · UI direction mockups

Three directions for the rebuilt frontend. All three run the same fake ecosystem and the same chart engine, so the comparison is layout, tone, and what a visitor is invited to do. Nothing here is the real simulation.

A · Observatory

Scientific dashboard · dark

Canvas center, dense right rail: KPI tiles, small-multiple population charts, FOV trend, inspector with genome heatmap, parameter sliders. Status bar with UPS, FPS, and shortcuts.

B · Console

Dashboard + command line · dark, monospace

Same charts, slimmer rail. A devtools-style console drawer logs ecosystem events and takes typed commands with Tab completion. A ⌘K palette replaces sliders. Homage to the current terminal.

C · Field Guide

Playful and illustrative · light

Warm light theme, bird sprites instead of triangles, plain-language copy, a "Meet a bird" card that narrates the selected agent, callouts on the canvas, and big friendly controls including a meteor button.

What is the same everywhere

PaletteHerbivores blue, predators orange, plants aqua: the first three slots of a colorblind-validated categorical palette, stepped separately for dark and light surfaces. Text never wears a series color.
ChartsPopulations use small multiples with a linked crosshair instead of one axis for 30 hawks and 1,200 seeds. Two-pixel lines, hairline grid, end labels, legend only where there are two or more series, hover tooltip listing every series, table view available.
InteractionClick an agent to select it. Space pauses. The selected agent shows its field-of-view wedge.

Hybrids are fine: for example A's rail with B's console drawer, or A's layout with C's sprites. Say which pieces.
